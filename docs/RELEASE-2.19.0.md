# AppShelf 2.19.0 — приёмка и выпуск

## Приёмка настоящего EXE — 21.11.2026

Все оставшиеся обязательные сценарии успешно проверены в опубликованном `AppShelf.exe` RC1 с SHA-256 `92097257137F447CBD8376ADB476B7ACA18DB85566C28E161112C1EB12294CE1`. Использованы Windows UI Automation, Win32-мышиный/клавиатурный ввод и настоящие окна приложения. Исходники, точка входа, сборка EXE и его внутренние объекты не подменялись. Это автоматизированная приёмка реального EXE, а не ручное пользовательское тестирование и не запуск изолированных WPF-тестов.

## Защита данных и результаты

- Рабочий экземпляр закрыт штатно. Весь рабочий профиль временно перемещён вне штатного пути, на его месте создан отдельный тестовый профиль.
- После проверки приложение полностью закрыто, тестовый профиль сохранён отдельно, исходный каталог возвращён без наложения и перезаписи файлов.
- Для всех **67 файлов** исходного профиля проверены количество и SHA-256: совпадают. Запись AppShelf в HKCU Run не изменилась.
- В тестовом профиле **не создан `error.log`**. Подтверждённых дефектов приложения не обнаружено; исправлений кода не потребовалось, RC2 не создавался.
- Снимки, UI-деревья, `status-events.csv`, `background-results.csv`, `compact-results.csv`, тестовый профиль и проверочные скрипты сохранены локально в `AppShelf-219-acceptance` внутри приватного временного каталога OpenCode. Они не входят в Git или Release; оригинальные пользовательские данные не публикуются.
- Ошибки автоматизации при первоначальном поиске поля файлового диалога и вводе Ctrl+A устранены в локальных проверочных скриптах: импорт затем успешно выполнен через настоящий диалог. Они не считались дефектами AppShelf и не потребовали изменения приложения.
- Проверки системного DPI и разных мониторов остаются отдельно отложенными по ROADMAP, без изменения согласованного объёма выпуска.

## Стабильная версия и финальные проверки

От RC1 меняются только `AssemblyInformationalVersion` на `2.19.0` и релизная документация. `AssemblyVersion` / `FileVersion` остаются `2.19.0.0`; встроенные заметки — для `2.19.0`. Код поведения приложения и опубликованный тег RC1 не меняются.

Финальная сборка стабильной версии выполнена стандартным `Build-AppShelf.cmd --no-start --no-pause`, код 0: `FileVersion=2.19.0.0`, `ProductVersion=2.19.0`, 507904 байта.

Полный регрессионный прогон стабильных исходников в Windows PowerShell 5.1 STA завершён перед объединением PR #48: **19 из 19 процессов с кодом 0**. Включены AppConfig, BackupReliability, CountdownTimer, DueReminders, HappRecovery, MainBackground, Package6Ui, ReleaseVersion, ReminderCalendarUi, ReminderDeliveryProcess, ReminderEditing, ReminderPanelAudit, RestoreBackup, SiteLinks, StartupSound, StartupWeather, Ui218, Ui219 и WeatherData.

`Package6Ui`: 66 сценариев без ошибок. `Ui219`: 10 сценариев без ошибок и необработанных исключений Dispatcher. Локальная сводка — `AppShelf-219-release/regression-20261121-011323/results.csv`. Снимки и сводные таблицы приёмки, включая `acceptance-summary.json`, сохранены отдельно от исходников.

Публикация привязана к итоговому коммиту `main` после объединения PR #48: окончательный EXE собирается из него, а равенство исходников приложения и тестов проверяется относительно прошедшей полный прогон ветки. Перед публикацией выполняется контрольный запуск именно финального EXE. Коммит, SHA-256 и результат проверки повторно скачанного asset фиксируются в заметках [стабильного GitHub Release 2.19.0](https://github.com/mishakov1c/app_shelf/releases/tag/2.19.0).

Проверки выполнены локально; успешный GitHub Actions не заявляется. Worktree, force-push, изменение RC1, PR #46, лицензии и видимости репозитория не выполнялись. Для предотвращения автоматической публикации другого бинарного файла merge-коммит не использует префикс `release: AppShelf`.
