# Продолжение выпуска AppShelf 2.19.0

> Исторический отчёт публикации RC1. Оставшаяся приёмка впоследствии завершена в настоящем EXE через Windows-автоматизацию. Актуальное решение и результаты — в [релизном отчёте 2.19.0](RELEASE-2.19.0.md).

Проверка начата 20.11.2026, публикация RC и итоговая сверка завершены 21.11.2026 по местному времени.

## Решение на момент публикации RC1

**Prerelease [2.19.0-rc.1](https://github.com/mishakov1c/app_shelf_archive/releases/tag/2.19.0-rc.1) опубликован с проверенным EXE. Стабильный выпуск 2.19.0 не опубликован, PR #48 не объединён:** полный приёмочный прогон неизменённого `AppShelf.exe` не подтверждён. Проверки тестовых WPF-сборок и частичный прогон EXE разделены ниже. Подтверждённых новых дефектов приложения в выполненных проверках не обнаружено; это не означает, что непроверенные сценарии прошли.

Читаемость текста на полностью белом пользовательском фоне принята пользователем. Это не дефект и не блокер выпуска; код оформления по этому поводу не менялся.

## Проверки неизменённого AppShelf.exe

Приложение запущено как отдельный процесс из стандартного EXE, без подмены исходников, точки входа и сборки. Использовалась Windows UI Automation; результаты не называются ручной пользовательской приёмкой.

| Проверка | Результат |
| --- | --- |
| Запуск с существующим профилем | Главное окно открыто, процесс отвечает |
| Поиск и сброс поиска | Получено 0 из 32, после очистки снова 32 из 32 |
| Окно «О программе» | Показана числовая версия 2.19.0 и встроенные заметки про непрозрачность 0–100% |
| Настройки → Внешний вид | Настоящее модальное окно открыто; исходное значение ползунка 67% |
| Непрозрачность 0/25/50/75/100% | Значения выставлены через UI Automation; снимки реального экрана и различающиеся пиксели подложки сохранены локально |
| Отмена настроек | После отмены `apps.json` не изменён относительно состояния перед изменением ползунка; пиксель подложки соответствует исходным 67% с допуском 2 единицы RGB |
| Сохранность пользовательского профиля | После возврата исходного раздела настроек `apps.json` и `reminders.json` побайтно совпадают с резервной копией перед запуском EXE |
| Журнал ошибок | `error.log` не увеличился |

До запуска профиль скопирован в приватный временный каталог вне репозитория. Восстановление всего профиля поверх пользовательских данных не выполнялось. Открытие раздела настроек штатно меняет `settingsLastSection` независимо от «Отмена»: исходный раздел возвращён через интерфейс. При работе приложения штатно изменились `apps.json.bak` и `weather-cache.json`; их не откатывали поверх текущих данных. Снимки экрана, профиль, резервные копии и персональные пути не публикуются.

Первая автоматическая проверка «О программе» прочитала дерево до появления модального окна. Повторное чтение подтвердило версию и заметки; это ошибка синхронизации проверочного сценария, а не подтверждённый дефект приложения.
