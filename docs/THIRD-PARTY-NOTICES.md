# AppShelf — сторонние погодные данные и условия

Этот документ описывает **данные внешних сервисов**, а не дополнительные библиотеки, встроенные в AppShelf. Собственный код AppShelf лицензирован по GNU GPL-3.0-only. Данные API, пользовательские фотографии и значки сторонних сайтов сохраняют свои условия.

## Open-Meteo

- Погода и геокодирование: [Open-Meteo](https://open-meteo.com/).
- Данные: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/); [условия и источники данных](https://open-meteo.com/en/license).
- Бесплатный endpoint Open-Meteo разрешён **для некоммерческого использования** в рамках [условий API](https://open-meteo.com/en/terms). Коммерческое использование сервиса требует соответствующего тарифа/соглашения. GNU GPL не меняет ограничения бесплатного API.
- Геокодирование городов может использовать базу GeoNames через Open-Meteo; Open-Meteo указывает [GeoNames как источник данных по CC BY](https://open-meteo.com/en/license).

## MET Norway

- Погода: [The Norwegian Meteorological Institute (MET Norway)](https://api.met.no/).
- Данные предоставляются согласно [политике лицензирования MET Norway](https://api.met.no/doc/License) под CC BY 4.0 / NLOD 2.0 (если не указано иное). [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- При использовании API соблюдать [Terms of Service](https://api.met.no/doc/TermsOfService), включая идентифицирующий User-Agent и контактный URL. AppShelf указывает канонический адрес проекта с GitHub Issues: `https://github.com/mishakov1c/app_shelf/issues`. Репозиторий уже переименован; открытая доступность адреса ожидается после перевода в Public.
- Приложение не использует и не распространяет чужие погодные пиктограммы Yr.

## Как AppShelf обрабатывает данные

AppShelf извлекает прогнозы, форматирует значения и подписи на русском языке, рассчитывает доступные дневные диапазоны из точек прогноза, сохраняет локальный кеш и показывает результаты в главной панели и окне «Прогноз на 7 дней». Эти действия означают, что исходные данные **преобразуются/агрегируются**; ссылки и подписи не означают одобрения AppShelf со стороны провайдеров. Данные могут быть прогнозными, а не фактическими измерениями.

В окне недельного прогноза указаны соответствующий поставщик и активные ссылки на условия и лицензии, а главная панель показывает источник в подсказке.

Права на локальные пользовательские изображения и favicon сайтов определяются их правообладателями. Они не включены в распространяемые исходники AppShelf.

## Перед публичной публикацией

Переименование `app_shelf_clean` в `app_shelf` завершено; перед Public остаётся проверить доступность ссылок для анонимного пользователя.

**Сжатие и перенаправления:** поддержка `Accept-Encoding: gzip, deflate`, автоматической распаковки и HTTPS-перенаправлений MET Norway принята после 5/5 ручных проверок на Windows и объединена в `main` (PR #7, 22.11.2026). Проверяется конечный HTTPS; переходов не более пяти. Open-Meteo оставлен с проверенным `identity`: его `deflate` ранее вызывал ошибку распаковки на .NET Framework. Лимит JSON 2 МиБ применяется к распакованному содержимому.

**HTTP-кэширование MET Norway — PR #8 объединён в `main` (22.11.2026):** оригинальный JSON с `Last-Modified` и `Expires` сохраняется в `met-http-cache.json` (до 6 местоположений, ограничение файла 20 МиБ). До `Expires` и консервативного интервала 3 часа одинаковый запрос обслуживается локально. После истечения срока используется `If-Modified-Since`; `304 Not Modified` повторно применяет сохранённый JSON. Принято 5/5 ручных сценариев на Windows и 5/5 изолированных HTTP-сценариев `200 → 304 → 200`. Реальный `304` от внешнего API отдельно не подтверждён. Open-Meteo и прежний кеш готового прогноза не изменены.

**Перед Public:** проверить доступность страницы Issues и ссылки на лицензии без авторизации. Владелец проекта подтвердил 22.11.2026, что лично ознакомился с [MET Norway Terms of Service](https://api.met.no/doc/TermsOfService) (редакция 05.11.2026) и принимает их. Это подтверждение дано владельцем, не ИИ. Проверить, что будущие EXE под GPL снабжены соответствующими исходниками.
