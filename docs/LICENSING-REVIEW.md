# AppShelf — проверка прав и лицензии перед публикацией

**Дата:** 22.11.2026. **Статус:** подготовка в приватном репозитории, не разрешение на публичную публикацию.

## Принятое решение

- Для исходного кода AppShelf выбрана **GNU GPL version 3 only**, SPDX: `GPL-3.0-only`. Не заменять её на `GPL-3.0-or-later`, MIT или прежнюю Proprietary Freeware License.
- Файл `LICENSE` должен содержать *без правок* полный стандартный текст GNU GPLv3 из [SPDX license-list-data](https://github.com/spdx/license-list-data/blob/main/text/GPL-3.0-only.txt).
- Предлагаемая строка указания авторских прав: `Copyright (C) 2026 mishakov1c`. Владелец должен подтвердить корректное указание правообладателя и право лицензировать все включённые части.
- Наличие текста GPL в черновой ветке само по себе **не доказывает права на чужие материалы** и не означает, что уже опубликованный исторический EXE автоматически сменил лицензию.

1. AppShelf написан на C# и WPF, ориентирован на Windows .NET Framework 4.8 и альтернативную публикацию .NET 8. В `AppShelf.csproj` не обнаружено `PackageReference` и сторонних библиотечных пакетов; `Build-AppShelf.cmd` ссылается на системные .NET/WPF-сборки. Это анализ текущего дерева, а не доказательство происхождения каждой строки кода.

   - `Assets/AppShelf.png`, 15 360 байт, Git blob `792603671bb74fc4e427b57a368ccbf0bcaa1f1a`;
   - `Assets/AppShelf.ico`, 37 546 байт, Git blob `7bb7c1c710ee13e60593fb1ec310797d004f85c6`.

Права на изображения пользователя и favicon определяются их собственными правообладателями.

## Погодные сервисы — отдельные условия, не лицензия на код

- **Open-Meteo:** бесплатный API предназначен для некоммерческого использования; погодные данные предоставляются по CC BY 4.0 с обязательной атрибуцией. Источник: [Open-Meteo Terms](https://open-meteo.com/en/terms), [Open-Meteo API](https://open-meteo.com/). Код GPL может использовать API, но GPL не даёт коммерческим пользователям право бесплатно пользоваться коммерческим тарифом провайдера.
- **MET Norway:** данные используются по CC BY 4.0 / NLOD 2.0 с указанием источника и ссылкой на лицензию, а API требует идентифицирующего `User-Agent` с контактными данными. Источники: [API Terms](https://api.met.no/doc/TermsOfService), [Data License](https://api.met.no/doc/License).
- Код показывает названия «Open-Meteo» / «MET Norway», но при проверке не найдено полного уведомления с ссылками на лицензии рядом с погодными данными. Кроме того, `AppShelf.cs` устанавливает `UserAgent = "AppShelf/2.5 (personal Windows desktop weather widget)"`, без контактного адреса или URL проекта. **Требуется уточнить и исправить перед публичным распространением.**
