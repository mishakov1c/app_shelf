# Обновления AppShelf из GitHub Releases основного репозитория

**Статус:** черновая реализация перенесена в чистый репозиторий поверх исходников AppShelf 2.19.0 из старого PR #46, но ещё не собрана и не проверена на Windows в новой ветке. Стабильная версия 2.19.0 работает без встроенного обновления. Перед первым запуском анонимной GitHub-проверки нужно завершить подготовку чистого репозитория, перенести релизы и перевести финальный `mishakov1c/app_shelf` в **Public**.

## Источник обновлений

- Единственный источник: **`mishakov1c/app_shelf`**, тот же репозиторий, где публикуются исходники и официальные релизы.
- GitHub API: `GET https://api.github.com/repos/mishakov1c/app_shelf/releases/latest`, без токена. С приватным репозиторием запрос без авторизации не работает.
- Вложение: `https://github.com/mishakov1c/app_shelf/releases/download/<tag>/AppShelf.exe`.
- Дополнительный `AppShelf-Releases` для работы обновлений **не нужен**. Приложение не предлагает выбор имени источника и не хранит соответствующую настройку.
- Запуск вручную через **`О программе → Проверить обновления`**. Фоновые проверки пока не реализованы.

## Контракт официального релиза

1. Опубликованный **стабильный** релиз (не draft и не prerelease), тег `2.19.0` или `v2.19.0`.
2. Вложение `AppShelf.exe`, обычная сборка Windows .NET Framework с `AssemblyName=AppShelf` и встроенной версией, совпадающей с тегом. Для самодостаточной .NET 8 сборки нужны отдельные проверки.
3. У вложения в ответе GitHub API должен быть `digest: sha256:<64 hex>`. Если он отсутствует, обновление блокируется.
4. Из описания релиза показывается текст изменений. Скачивание и установка возможны только после явного подтверждения пользователя.
5. EXE загружается из официального HTTPS URL релиза с проверкой размера, контрольной суммы и встроенной версии. Это **контроль целостности относительно GitHub**, не криптографическая подпись автора.

Пример будущей штатной ручной публикации проверенного EXE (синтаксис, не выполнять сейчас; номер версии будет выбран позднее):

```powershell
gh release create X.Y.Z AppShelf.exe --repo mishakov1c/app_shelf --title "AppShelf X.Y.Z" --notes-file release-notes.md
```

## Установка

1. Скачанный EXE помещается во временную папку `%LOCALAPPDATA%\AppShelf\Updates\...`; размер и SHA-256 проверяются до установки.
2. Существующая версия AppShelf копируется в отдельный исполняемый файл-помощник. После подтверждения обновления AppShelf закрывается, а помощник ожидает завершения основного процесса.
3. Помощник повторно проверяет SHA-256 и заменяет исполняемый файл через `File.Replace`, сохраняя прежний EXE как `AppShelf.exe.previous` для отката.
4. Затем запускается новая версия. Если замена не удалась, исходный EXE должен сохраниться; предусмотрена попытка запустить старую версию.
5. Пользовательские данные `%APPDATA%\AppShelf` обновлением не перезаписываются.

## Ограничения перед выпуском

- Чистый репозиторий содержит только импортированный снимок актуальных файлов, без прежней Git-истории. Перед переводом в Public требуются завершение переноса, проверка прав на ресурсы и отдельное оформление GPL-3.0-only. Эта работа не меняет видимость репозитория.
- Необходимо проверить компиляцию, UI и полный цикл установки на **отдельной тестовой копии**, а не на личной рабочей программе.
- Установка требует доступа на запись к каталогу EXE. Повышение прав без согласия не выполняется.
- Сейчас нет проверки по расписанию, принудительных обновлений, цифровой подписи файла и автоматической очистки старых временных каталогов.
- Код обновления находится в ветке разработки и не должен считаться готовым к релизу без локальных проверок.
